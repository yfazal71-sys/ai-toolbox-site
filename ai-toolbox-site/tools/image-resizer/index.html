What is the Image Resizer?

An image resizer changes the pixel dimensions of a picture. Use it to fit a profile photo, a blog layout or an upload limit.

How to use it

  1. Choose an image
  2. Enter a width, a height, or both
  3. Download the resized file

Example

A 4000 x 3000 photo resized to width 800 becomes 800 x 600.

Benefits

Right-sized images load faster and fit form requirements.

Frequently asked questions

Will resizing reduce quality?

Making an image smaller keeps it sharp. Enlarging can look soft.

Is there a size limit?

Output is capped at 8000 px per side to protect low-memory phones.
