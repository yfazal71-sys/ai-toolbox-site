What is a QR code generator?

A QR code is a square pattern that a phone camera can read. It can hold a web address, plain text or contact details. This tool turns the text you type into that pattern so you can print it or share the image.

How to use it

  1. Type or paste a link or text
  2. Choose a size and an error correction level
  3. Scan the preview with your phone to check it, then download the PNG

Example

Typing a link such as https://example.com produces a code that opens that page when scanned.

Benefits

Handy for posters, business cards, menus and sharing a link with people nearby. Higher error correction keeps the code readable if part of it is damaged, but makes it denser.

Frequently asked questions

Is my text sent to a server?

No. The QR code is drawn in your browser, so your text is not uploaded.

Will the QR code expire?

No. The code stores the text itself, so it works as long as the printed or saved image stays readable.
