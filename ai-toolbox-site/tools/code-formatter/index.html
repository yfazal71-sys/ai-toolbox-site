Code Formatter

Format, validate and minify JSON. Errors are shown with details. Free, no sign-up.

Privacy: Your text or file stays in your browser and is not uploaded to our server.

What is the Code Formatter?

A JSON formatter makes data readable by adding indentation, and checks that it is valid. It can also strip whitespace to make the file smaller.

How to use it

  1. Paste JSON
  2. Choose indent or minify
  3. Copy or download the result

Example

{"a":1,"b":[2,3]} is expanded into indented lines, or an error explains what is wrong.

Benefits

Spot missing commas and quotes quickly.

Frequently asked questions

Which languages are supported?

JSON only for now.

Is my data sent anywhere?

No. Parsing happens in your browser.
